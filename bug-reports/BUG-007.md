# [BUG-007] Calendar Allows Users to Select Past Dates

**Status:** Open
**Priority:** Low
**Severity:** Low
**Module:** Calendar / Date Selection
**Environment:** Frontend / Local Development

## Description

The calendar interface allows users to navigate to and select dates in the past.

The selected past date is displayed normally, even though the backend later rejects booking creation for a past date.

## Preconditions

1. Frontend application is running.
2. Calendar page is opened.
3. Booking timeline is available.

## Steps to Reproduce

1. Open the booking calendar.
2. Navigate to a previous date using the calendar or previous-date arrow.
3. Select a date in the past.
4. Observe the calendar and timeline.
5. Attempt to create a booking for the selected past date.

## Expected Result

Past dates should be disabled in the calendar.

The user should not be able to navigate to or select dates that cannot be used for booking.

The previous-date navigation should be disabled when the current date is reached.

## Actual Result

The user can navigate to past dates and select them.

The past date is displayed as a normal calendar date.

The booking flow proceeds until the backend validation rejects the request with:

```
400 Bad Request
```

## Suggested Fix

Disable past dates directly in the calendar component.

For example, configure the date picker with the current date as the minimum selectable date:

```
min={today}
```

Also disable the previous-date navigation control when the current date is reached.
