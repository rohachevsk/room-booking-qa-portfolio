# Room Booking Service — QA Portfolio Project

## 📌 Описание проекта
Данный репозиторий содержит полный цикл QA-тестирования (Manual API & Database & UI Testing) для веб-приложения бронирования переговорных комнат **Room Booking Service**.

Проект выполнен в рамках формирования портфолио Junior QA Engineer с акцентом на тестирование REST API, бизнес-логику транзакций (Race Conditions) и работу с базами данных PostgreSQL.

## 🛠 Технологический стек приложения
- **Backend:** Node.js, Express 4.21, TypeScript 5.7, Prisma ORM 5.22
- **Database:** PostgreSQL
- **Frontend:** React SPA (Vite)
- **Architecture:** Monorepo (npm workspaces)

## 🎯 Инструменты и методы тестирования
- **API Testing:** Postman (Collections, Environments, Dynamic Scripts)
- **Database Control:** PostgreSQL (SQL-запросы, проверка состояний)
- **Test Design:** Equivalence Partitioning, Boundary Value Analysis, Pairwise
- **Documentation:** Test Plan, Checklists, Test Cases, Bug Reports, Test Summary Report

## 📂 Структура репозитория
- `/docs` — Стратегия, чек-листы и тест-кейсы
- `/postman` — Экспортированные коллекции Postman и окружения
- `/bug-reports` — Документированные дефекты
- `/sql` — SQL-скрипты, использованные при тестировании
